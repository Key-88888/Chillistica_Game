# Chillistica_Game

Автозапрет — обход блокировок (DPI bypass) для YouTube, Discord, Roblox и Fortnite одной кнопкой. Windows 10/11 x64.

## Скачать

**Официальный релиз (GitHub):**
- Последняя версия: <https://github.com/Key-88888/Chillistica_Game/releases/latest>
- Нужен файл `Chillistica_game-vX.Y.Z-win-x64.zip`.

### Если GitHub не открывается / файл не качается без VPN

GitHub отдаёт файлы релизов с хоста `objects.githubusercontent.com`, который в РФ часто режется DPI (та самая проблема, которую и решает эта программа — «замкнутый круг» при первой установке). Варианты без VPN:

- **Зеркала-прокси GitHub (сторонние):** подставьте перед ссылкой на файл один из прокси:
  - `https://ghproxy.net/` + ссылка на файл
  - `https://gh-proxy.com/` + ссылка на файл

  Пример:
  `https://ghproxy.net/https://github.com/Key-88888/Chillistica_Game/releases/download/v0.4.2/Chillistica_game-v0.4.2-win-x64.zip`

  > Зеркала — сторонние сервисы, не под нашим контролем. По возможности качайте с официального GitHub; после установки приложение обновляется само и проверяет подпись каждого обновления встроенным ключом.
- Либо: мобильный интернет другого оператора, Cloudflare WARP, или скопировать архив с другого ПК по USB.

## Установка

1. Распаковать `Chillistica_game-vX.Y.Z-win-x64.zip`.
2. Запустить **`install.cmd`**.
3. Подтвердить запрос прав администратора (UAC).
4. После установки приложение откроется само. Ярлык **Chillistica_game** появится на рабочем столе и в меню «Пуск».

Программа ставится в `C:\Program Files\Chillistica_game\` (служба + приложение).

## Антивирус

Движок обхода (`winws.exe`) и драйвер `WinDivert` антивирусы часто помечают как PUA — это нормально для инструментов такого класса. Если приложение пишет **«Служба не запущена / заблокирована антивирусом»**:

1. Откройте антивирус/Защитник Windows → журнал/карантин.
2. Восстановите файлы Chillistica_game, если они были удалены.
3. Добавьте папку `C:\Program Files\Chillistica_game` в исключения.
4. Проверьте, что служба `Chillistica_game.Service` запущена (`services.msc`).

## Обновления

Приложение само проверяет наличие новой версии и предлагает установить её в один клик. Каждое обновление скачивается по HTTPS только с GitHub и проверяется по встроенному в сборку открытому ключу — подделать или подменить обновление нельзя.
