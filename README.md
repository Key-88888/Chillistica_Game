# Chillistica_Game

Обход блокировок (DPI bypass) для YouTube, Discord, Roblox и Fortnite одной кнопкой на Windows 10/11 x64. Движок — winws ([zapret](https://github.com/bol-van/zapret)) + WinDivert.

Версия: **0.5.0**.

## Скачать

Последняя версия доступна на [странице релизов GitHub](https://github.com/Key-88888/Chillistica_Game/releases/latest).

Есть два варианта загрузки:

| Архив | Размер | Когда брать |
|---|---|---|
| `Chillistica_game-vX.Y.Z-win-x64.zip` | ≈ 1,4 МБ | Основной. Требует .NET 8 Desktop Runtime; если его нет, `run-first.cmd` поставит среду сам. |
| `Chillistica_game-vX.Y.Z-win-x64-standalone.zip` | ≈ 59 МБ | Если .NET ставить нельзя или нет интернета на целевой машине — работает сам по себе. |

Берите первый: 1,4 МБ скачиваются за секунду и гораздо реже обрываются на плохом канале.

### Если GitHub не открывается или архив не скачивается

Сам `github.com` в России обычно доступен, а вот файлы релизов отдаются с `objects.githubusercontent.com` — его нередко режет DPI. Симптом: страница релизов открылась, а загрузка встала на нуле или оборвалась на середине.

Что можно сделать:

- **Взять маленький архив** (1,4 МБ) вместо standalone — короткая загрузка часто проскакивает там, где длинная рвётся.
- **Зеркало-прокси**: добавить перед ссылкой на архив `https://ghproxy.net/` или `https://gh-proxy.com/`. Например:
  `https://ghproxy.net/https://github.com/Key-88888/Chillistica_Game/releases/download/v0.5.0/Chillistica_game-v0.5.0-win-x64.zip`
  Зеркала — сторонние сервисы, они не под нашим контролем; после скачивания обязательно сверьте хеш (ниже).
- **Другая сеть**: мобильный интернет, Cloudflare WARP, либо перенести архив с другого компьютера через USB.

### Проверка скачанного архива

Оборванная загрузка выглядит как обычный ZIP, поэтому сверьте размер и SHA256 с теми, что указаны в описании релиза:

```powershell
Get-FileHash .\Chillistica_game-v0.5.0-win-x64.zip -Algorithm SHA256
```

Если хеш не совпал — архив повреждён или скачан не оттуда, запускать его не нужно.

## Установка и запуск

1. Скачайте подходящий ZIP-архив.
2. Распакуйте его в отдельную папку.
3. Запустите `run-first.cmd` двойным щелчком (или напрямую `Chillistica_game.exe`).
4. Подтвердите запрос контроля учётных записей (UAC).
5. Нажмите «Включить защиту».

**НЕТ службы, НЕТ установки — просто распаковали и запустили.** Приложение само запускает `winws.exe` с необходимыми правами.

### Обновление с версии 0.4.x

В версиях до 0.5.0 работала фоновая служба Windows. Новая версия её не использует и **не удаляет автоматически** — старая служба останется в системе, продолжит запускаться под SYSTEM и может конфликтовать с новым движком. Удалите её один раз, из командной строки, запущенной от имени администратора:

```
sc.exe stop Chillistica_game.Service
sc.exe delete Chillistica_game.Service
```

Если команда отвечает, что служба не найдена, — значит её и не было, всё в порядке. После этого старую папку можно удалить целиком: новая версия ничего оттуда не берёт.

## Антивирус

Антивирусы часто помечают `winws.exe` и WinDivert как PUA. Это нормально для инструментов такого класса: они перехватывают и изменяют сетевой трафик, чтобы обходить DPI.

Если антивирус удалил или заблокировал файлы, восстановите их из карантина и добавьте распакованную папку Chillistica_game в исключения.

## Обновления

Приложение само проверяет GitHub и показывает баннер, когда выходит новая версия. Кнопка «Обновить» скачивает архив вместе с отсоединённой подписью и **проверяет подпись встроенным в программу ключом** — только после этого архив открывается в проводнике. Дальше закройте программу, распакуйте архив поверх текущей папки и запустите заново.

Если ключ проверки в сборку не встроен, обновления просто отключаются: неподписанное обновление не предлагается и не скачивается.
